🚀 Stage 1: Quick Start in 60 Seconds

Creating your first professional MapTip card in QGIS takes only four clicks.

1. Select Active Layer Pick any polygon, line, or point vector layer in your QGIS project from the top Layer combo box.
2. Click a Preset Chip Click 🏢 KPI, ⚡ Bar, 🍩 Donut, or 📈 Trend to immediately load a balanced configuration.
3. Click 'Apply MapTip' Click the primary green 🚀 Apply MapTip to Layer button at the bottom of the designer tab.
4. Hover on Canvas Ensure the MapTips icon on the QGIS canvas toolbar (or the dock iOS switch) is ON, and hover over map features!
Pro-Tip: Use the Sample Feature Navigator (◀ Prev, Next ▶, 🔀 Cycle) right above the Rendered Card preview. You can test your card design against live feature values without closing or switching panels.

🎨 Stage 2: Choosing the Right Layout Archetype

Every dataset tells a different story. Qgis MapTips provides five universal visual archetypes engineered specifically for the Qt QTextDocument rendering subsystem:

Archetype Visual Focus Best Suited For Generated Technology
KPI Card Prominent headline number with unit badge and key-value metadata rows. Real estate prices, cadastral areas, inspection scores, asset IDs. Clean Qt HTML nested tables with contrast text tokens.
Progress Bar Comparative target percentage bar showing current vs maximum capacity. Reservoir levels, zoning density limits, budget spend, occupancy rate. Qt table-cell percentage clamping (clamp(0.0, ..., 100.0)).

Media / Photo Card Centrally framed image thumbnail with graceful missing-photo placeholder. Field surveys, infrastructure photos, building facades, damage assessments. Expression-wrapped <img> with SVG null fallback.

⚙️ Stage 3: Precision Data Formatting & Null Safety

Raw GIS datasets often contain unformatted floating-point numbers (e.g. 14528.39847192) or empty/NULL fields that look amateurish in standard tooltips. Qgis MapTips solves this at the expression level:

  • Automatic Number Formatting (format_numbers=True): Integer values automatically receive thousands grouping commas (e.g. 1,250,000). Floating-point values are rounded and formatted to your configured decimal precision (e.g. 254.50).
  • Clean Missing Value Fallbacks: Any NULL, empty, or whitespace attribute is replaced with an elegant dash (—) or custom text instead of displaying an ugly blank space or raw NULL string.
  • Photo Fallback Engine: If a feature does not have a valid photo URL or path, the card displays a clean 📷 No Photo Available SVG placeholder rather than a broken image box with an 'X'. Alternatively, choose hide mode to collapse the photo row entirely when no image is present.
-- Generated QGIS expression for safe attribute display:
CASE 
  WHEN "area_m2" IS NULL OR length(trim(to_string("area_m2"))) = 0 THEN '—' 
  WHEN try(to_real("area_m2"), NULL) IS NOT NULL THEN (
    CASE WHEN to_real("area_m2") = round(to_real("area_m2"), 0) 
      THEN format_number(to_real("area_m2"), 0) 
      ELSE format_number(to_real("area_m2"), 2) END) 
  ELSE to_string("area_m2") 
END

⚡ Stage 4: The 1-Click Layer Actions Hub

QGIS Layer Actions allow map users to trigger external web navigation, run desktop scripts, or select intersecting data. Qgis MapTips makes action creation as simple as checking a box:

🌍 Google Maps Satellite Opens the exact feature location in Google Maps satellite view with dynamic WGS84 point-on-surface transformation.
🚶 Google Street View Launches a full 360-degree street panorama centered on the feature in your default browser.
🗺️ OpenStreetMap & Yandex 1-click links to OSM standard cartography or Yandex Maps high-resolution aerial imagery.
📋 Copy to Clipboard Copies all formatted attributes of the clicked feature directly into the system clipboard.
📄 Export HTML Card Report Renders a standalone, printable HTML portfolio card for the feature and opens it in your browser.
🔗 Open File / Photo Opens any local PDF, CAD drawing, document, or photo referenced in an attribute field using the default OS application.
3 Ways to Trigger Injected Layer Actions in QGIS:
  1. Inside the MapTip Card: Hover over a feature and click the action pills (e.g. 🛰️ Sat, 🚶 Street, 📋 Copy) rendered directly inside the card footer.
  2. On Map Canvas: Click the yellow gear icon (Run Feature Action on the QGIS canvas toolbar or click 🎯 Canvas Action Tool in the dock) and click any feature on the map.
  3. In Attribute Tables: Right-click any row in the Attribute Table or Identify Results panel and select the action from the context menu.

🇹🇷 Stage 5: Instant Canvas Cadastre Picker (Turkey Only)

For urban planners, architects, surveyors, and civil engineers working in the Republic of Turkey, Qgis MapTips includes an interactive 1-click cadastral parcel tool connected to the official TKGM MEGSİS API.

1. Activate Canvas Tool Under Actions Hub, click ⚡ Click Canvas to Download Parcel. The cursor becomes an amber reticle target.
2. Click Anywhere on Map Click on any building footprint, satellite image, or blank canvas inside Turkey. No vector layer is required.
3. Instant Polygon Layer The official boundary geometry is retrieved and added into the TKGM Parselleri (TR) memory layer.
4. Automatic Styling & Labels The layer is styled in Cadastral Amber with automatic centered ada_no / parsel_no text labels and text buffer.
Fair-Use Notice & Quota: The official TKGM MEGSİS service enforces an IP-based fair-use rate limit (approximately ~100 requests per day per IP address). If exceeded, the server returns HTTP 403 Forbidden. The plugin handles this gracefully with a clear Turkish notification. Quotas typically reset at midnight. 🎯 Stage 6: Live Canvas Hover HUD (Raster Inspector)

Working with heavy digital elevation models (DEM), slope rasters, thermal imagery, or multi-spectral satellite orthophotos often requires tedious point sampling with the Identify tool. Live Canvas HUD offers a passive, non-intrusive alternative:

  • Real-Time Canvas Inspection: Simply move your mouse across the canvas to sample pixel values continuously.
  • Dwell Debouncing (100–1000 ms): Built-in debouncing ensures that fast mouse movements across the screen do not trigger expensive raster pixel fetches, guaranteeing silky smooth 60 FPS canvas panning and zooming.
  • Precision Reticle Cursor: Replaces the standard pointer with a high-contrast reticle crosshair and target indicator.
  • Stationary Pin/Freeze: Press Shift + Click anywhere on the map to freeze the current tooltip in place so you can read, compare, or copy values without moving your hands.
  • Composite Multi-Layer Mode: Inspect multiple visible raster layers plus the top vector polygon attribute in a unified, multi-band inspection card.
  • Permanent Dock Console: All sampled values stream into the dock's Live Sampled Values Feed and remain readable even when your mouse leaves QGIS.

❓ Frequently Asked Questions (FAQ)

Q: Do clients or colleagues need this plugin installed to view the cards?
A: No! That is the core superpower of Qgis MapTips. The generated HTML expressions and action configurations write directly to native QGIS layer definitions. Any user opening your .qgz project in standard QGIS will see the styled cards and action pills.

Q: Does this plugin slow down QGIS canvas rendering?
A: Not at all. All charts are generated as pure nested HTML tables or compact SVG data-URIs. There are zero JavaScript engines, zero Chromium subprocesses, and zero external network calls during normal map browsing.

Q: Is QGIS 4 supported?
A: Yes. The plugin has been rigorously audited with dual-runtime test harnesses on both QGIS 3.28+ LTR and QGIS 4.2.0, adhering strictly to Qt6 scoped enum guidelines.
